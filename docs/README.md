# CarVenta Documentation & Archive

This directory contains supplemental documentation, architectural design notes, and project audit records for the **CarVenta** platform.

## Directory Structure

- **`archive/`**: Contains historical feature specifications, technical presentation prompts, and pre-release security audit reports.
  - `clean.md` / `PUBLIC_RELEASE_AUDIT.md`: Pre-release audit criteria and guidelines.
  - `PUBLIC_RELEASE_AUDIT_REPORT.md`: Baseline security audit findings.
  - `PUBLIC_GITHUB_RELEASE_REPORT.md`: Comprehensive remediation matrix and variable inventory.
  - `ADMIN_SOLUTIONS.md` / `CORE_FEATURES_IMPLEMENTED.md` / `NEW_FEATURES.md`: Feature implementation history.
  - `REPLIT_PROMPT_PRESENTATION.md` / `REPLIT_PROMPT_TECHNICAL_REPORT.md`: Presentation generators.

For primary project setup, configuration, and developer guidelines, refer to the root [README.md](../README.md).
